## 现在的能力

- **入口**：右下角、模型选择器左侧一枚 `∑`（`order: 1000`，紧贴模型）；28×28 热区 + 30×30 G2 细框（静止 26%，悬停 62% + 4.5% 填充，焦点品牌色）。
- **面板**：4 组 32 个符号（含 `∫ ∮ ∂`）、数字键盘、`空格（次方）`、`⌫`、可编辑草稿、实时“读作”；右上角 `TeX` 可把草稿转成 LaTeX（搜索框已移除）。
- **两种模式**：草稿（拼好一次插入）/ 直插（点一下直接进聊天框，面板不关）。
- **约定不变**：`sin3x → sin(3x)`、`sin3 x → sin³x`、`e3 → e³`、`x5 → x⁵`；开 `TeX` 后插入 `\lim_{x \to 0} \sin x` 这类 LaTeX。
- **插入**：打开时记录光标 + 草稿版本，版本冲突自动重试 3 次，仍失败写剪贴板兜底。

## 中间最大的坑

v3.2 / v3.3 / v3.4 你说“没区别”，不是审美问题：**样式表写在弹窗组件的返回值里**，弹窗一关组件返回 `null`，`<style>` 跟着卸载——触发按钮平时是浏览器默认按钮（灰底方块、默认字号、不居中）。v3.5 才把它修掉：样式改为 `apply(ctx)` 一次性注入 `<head>`，并用冒烟测试断言“安装后必须恰好有一份包含 `.mss-trigger` 的样式表”。
